# Tax Working Group

## Goals
The Tax Working Group determines what a payment protocol must record for a transaction to be accountable for under existing tax, accounting, and reporting law. We work from obligations that are in force rather than predicted, and we treat the protocol's job as anchoring facts rather than carrying them. Our output is a set of normative, testable requirements, each derived from a stated foundation principle and each filed so that a third party can demonstrate compliance or violation.

Goals of the WG are:

1. Establish the lawful floor: the minimum set of obligations in force that any conforming implementation must be able to satisfy, each recorded with its trigger, responsible party, required facts, timing, evidence, and treatment when facts are missing.
2. Derive normative requirements from those obligations, each citing a parent principle, so that unjustified requirements and untested principles are both visible.
3. Keep regulatory research and normative text in separate artifacts, so that prose that explains is never mistaken for text that binds.
4. Provide explicit extension points for future regulatory models rather than encoding predictions in the core.
5. Maintain the open questions requiring practitioner, counsel, or technical validation as a public record, resolved into requirements, documented non-requirements, or referrals.
